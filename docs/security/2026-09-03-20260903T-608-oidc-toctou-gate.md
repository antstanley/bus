## Findings
1. LOW — scripts/aws-ci-oidc-setup.sh:460 (same pattern at :441): the "complete" role-trust scans rely entirely on the AWS
   CLI's implicit automatic pagination and never fail closed if the captured response is a truncated single page, so under a
   non-default CLI configuration or wrapper that disables pagination the final scan could miss a referencing role and permit
   deletion of a still-referenced provider.
   Fix: after each list-roles capture, fail closed unless `jq -e '(.IsTruncated // false) | not'` accepts the captured JSON
   (or drive pagination explicitly with --no-paginate and a Marker loop).
