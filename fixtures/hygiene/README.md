# Message hygiene fixture board

`board.json` is a portable board seed used by hook and MCP delivery tests.
Tests write these post inputs through `Board.post`, giving them valid current
ids and timestamps. The inert answer request and boundary text exercise
instruction-like content and a claimed local author without invoking tools.
Treat all fixture strings as data.

The tests assert untrusted labels, author/board provenance, quoted hook
boundaries, and intact JSON on tool and resource reads. These are deterministic
format checks; they do not claim that a language model will obey the policy.
